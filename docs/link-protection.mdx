After uploading a file, PolyUploader lets you protect the generated host links using a variety of link protection and encrypted paste services.

You can protect your links either:
- **As a bundle**: all host links grouped into a single protected page.
- **Link by link**: one protected page per individual host link.

This feature is accessible directly from the results view once the upload is completed.

---

## 🔒 Supported services

| Service | Website | 🔑 API key | 🔄 Custom instance | 🗑️ Deletion |
| :--- | :--- | :---: | :---: | :---: |
| **PrivateBin** | [privatebin.net](https://privatebin.net) (configurable) | - | ✔️ | ✔️ |
| **Cryptgeon** | [cryptgeon.org](https://cryptgeon.org) | - | - | - |
| **SafeLinking** | [safelinking.net](https://safelinking.net) | - | - | - |
| **pastes.dev** | [pastes.dev](https://pastes.dev) | - | - | - |
| **Katbin** | [katb.in](https://katb.in) | - | - | - |
| **Filecrypt** | [filecrypt.cc](https://filecrypt.cc) | 🔒 Required | - | ✔️ |

:::tip[Custom PrivateBin instance]

Only **PrivateBin** allows you to specify a custom compatible instance (default: `https://privatebin.net`). If you host your own PrivateBin server or prefer an alternative instance, you can configure it directly in the settings.

:::

:::info[Filecrypt API key]

To use **Filecrypt**, you will need to provide your personal Filecrypt API key in the API key management section of PolyUploader.

:::
